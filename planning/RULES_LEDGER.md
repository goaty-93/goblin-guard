# Rules ledger

Checked: 24 August 2026

## Confirmed from the event page

- Event: Alpaca AI Trading Agents Hackathon.
- Online build window: 28 August–4 September 2026.
- Prize pool shown on the signed-in dashboard and current event page: $6,000.
- Challenge: build AI trading agents and trading applications on Alpaca using
  the Trading API, MCP server, or CLI.
- The event describes development and testing in Alpaca's paper-trading
  environment.
- Teams may contain one to six people; Goblin Guard is currently a solo team.
- Judging dimensions are Presentation, Business Value, Application of
  Technology, and Originality.

## Confirmed from the rendered LabLab rule book

- A public GitHub repository is mandatory.
- A hosted, interactive application URL is required.
- The rule book names Streamlit, Replit, or Vercel as hosting examples/options.
- A PNG or JPG cover image is required, with 16:9 recommended.
- The video must be MP4 and no longer than five minutes.
- The slide presentation must be PDF.
- Missing required submission material may lower the score or cause exclusion.
- Manual submission is available for six hours after the hackathon only with a
  valid reason and prior organizer or mentor approval. This is not a planned
  fallback.
- Plagiarism, voting manipulation, unauthorized automation, fraud, or other
  conduct that undermines the event may cause disqualification.

## Confirmed from the rendered submission guide

- Title: clear and descriptive.
- Short description: no more than 255 characters.
- Long description: at least 100 words and should cover the problem, solution,
  target audience, and differentiators.
- Technology and category tags are required.
- Submission checklist: title, short and long descriptions, tags, cover image,
  video, slide presentation, GitHub repository, and application URL.

2. If yes, what disclosure and commit-history evidence is expected?
3. Must all submitted code be MIT licensed, or merely open source under an
   approved license?
4. Must the new repository be created after kickoff, or is an empty/preparatory
   repository permitted beforehand?
5. Is use of Alpaca's Trading API sufficient, or is MCP or CLI specifically
   required for prize eligibility?
6. Are paper orders required, or can an agent that stops at a trade proposal be
   eligible? Goblin Guard plans paper orders unless told otherwise.
7. Are external LLM providers permitted, and are any models or sponsors
   preferred or required?
8. What is the exact submission deadline in Europe/London time?
9. Does the event require build-in-public updates or any additional sponsor
   deliverables?
10. Does the generic submission page's current IBM Bob wording apply here? It
    appears unrelated to this Alpaca event and must not be assumed applicable.
